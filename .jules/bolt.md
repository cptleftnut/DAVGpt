## 2026-06-18 - Chat Input Lag & MessageBubble Re-renders
**Learning:** In a highly interactive chat interface, mapping over a growing list of message components (like `MessageBubble` in `App.tsx`) causes O(N) re-renders on every keystroke if the parent component manages the input state. This is especially problematic when the message component contains expensive operations, such as O(N) regular expression parsing for code blocks (`parseBlocks`).
**Action:** When a parent component updates frequently (e.g., typing in a text area), ensure that child list items are wrapped in `React.memo`. If the parent passes inline functions or complex objects (like `onRunCommand` in this app), standard `memo` will fail to prevent re-renders. Use `React.memo` with a custom comparison function that only checks the actual primitives necessary for the child component's display.
