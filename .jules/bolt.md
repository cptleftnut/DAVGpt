## 2024-06-19 - Unnecessary O(N) Regex Parsing in React Chat Rendering
**Learning:** In applications where a parent component (like `Chat`) maintains high-frequency state (like an `input` field from typing), all child components (like `MessageBubble`) will re-render by default on every state change. If the child component performs expensive operations on render (such as parsing markdown using regex in `parseBlocks`), it causes a hidden O(N) performance bottleneck on every keystroke, where N is the number of rendered messages.
**Action:** When implementing chat interfaces or long lists, always apply `React.memo()` to list items (`MessageBubble`) to detach them from parent state updates (like `input` fields). Additionally, memoize expensive derivations like regex parsing (`useMemo`) to ensure that even if the component re-renders for other reasons (e.g. `speaking` or `connState`), the expensive operation is skipped if the raw `content` hasn't changed.
